# Консольна база даних замовлень клієнтів (C++)

Повністю автономний консольний застосунок для управління даними клієнтів (CRUD). Програма не потребує встановлення стороннього програмного забезпечення, додаткових серверів чи СКБД — уся інформація зберігається локально у текстовому файлі.

Розгортання та запуск

Встановлення є максимально інтуїтивним. Створіть на жорсткому диску робочу папку для програми та оберіть один із варіантів запуску:

Варіант 1: Швидкий запуск
1. Завантажте готовий виконуваний файл `.exe` з репозиторію.
2. Помістіть його у вашу робочу папку.
3. Запустіть файл подвійним кліком лівої кнопки миші.

Варіант 2: Компіляція з вихідного коду
1. Склонуйте репозиторій або завантажте вихідні файли: `main.cpp`, `Database.cpp`, `Database.h` та `Order.h`.
2. Відкрийте їх у будь-якому зручному компіляторі (наприклад, VS Code) та переконайтеся, що всі модулі знаходяться в одній директорії.
3. Скомпілюйте застосунок (приклад для GCC):
   ```bash
   g++ main.cpp Database.cpp -o orders_app
4.Запустіть створений файл з розширенням .exe подвійним натисканням лівої кнопки миші.
